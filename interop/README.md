# Независимый тестовый стенд совместимости

Версия программы 0.9.0. Редакция 12.11.2026.

## 1 Назначение и статус

`peer.py` содержит отдельные HTTP-среду и контроллер на стандартной библиотеке Python. Они не импортируют hackroi, его схемы, физику и клиента. Это собственный проверочный стенд, а не решение другой команды и не официальный эталон организаторов. Он выявляет зависимости от авторских имён, параметров и описания ресурсов; независимость автора или языка реализации не утверждается.

Среда использует другую область координат, собственные правила ресурсов, скорость, зарядку и препятствие. В режиме partial первая команда первого шага честно отклоняется без исполнения; конфигурация применяется целиком. Наш контроллер должен учитывать фактический ответ, а не выдумывать подтверждение.

## 2 Публичная семантика

Машиночитаемая декларация: public_model_profile.json. Примеры отличий: navigate/destination вместо move/target, inspect/object_id вместо observe/target_id, battery и cargo вместо energy и supplies, box/lower/upper вместо axis_aligned_box/min/max. Связь задаётся явно через semantic, parameter_mapping, motion_limits и energy_limits. Без такой декларации значение не угадывается по имени или закрытому коду среды.

Профиль является дополнением к HTTP 1.0, а не новым обязательным протоколом хакатона. Для неизвестного описания физики необходим отдельный публичный адаптер. В базовом профиле используются ограниченные плановые допущения; неизвестные обязательные ограничения вызывают безопасную реакцию. Актуальные пределы — docs/PROTOCOL.md. Для dt, отличного от 1 секунды, публикуется dt_seconds; контроллер переводит скорость и часы в модельные такты и возвращает исходное время в HTTP.

## 3 Запуск отдельно

```powershell
py -3.12 interop/peer.py environment --port 8100 --log-path artifacts/peer/environment.jsonl
py -3.12 -m hackroi controller --portable --environment-url http://127.0.0.1:8100
```

Добавьте --partial или --dt 0.5 к среде для соответствующей проверки. Контроллер независимого стенда запускается так:

```powershell
py -3.12 interop/peer.py controller --environment-url http://127.0.0.1:8000 --log-path artifacts/peer/controller.jsonl
```

Он публикует собственный controller/health и использует сценарий foreign_rescue. Полная матрица двух реализаций и контроль исходных журналов запускаются scripts/run_stage5.py.

## 4 Отказы

`faults.py` — отдельный локальный инъектор повреждённых ответов. Он не входит в рабочий контроллер. Потеря ответа после фиксации шага проверяется как неопределённое подтверждение: ровно один step-запрос, реально один шаг, никакого автоматического повторного шага. Ошибочная ссылка на чужой episode_id не используется для закрытия чужого эпизода.

## 5 Внешние среды

В этой поставке не задано адресов других команд. Подключение конкретного предоставленного стенда:

```powershell
py -3.12 scripts/run_external.py --url http://HOST:PORT --output artifacts/external_check
```

Запуск начинает собственный reset; среда должна быть свободна. Параметры по опубликованной декларации можно передать через --parameters settings.json, таймаут — --timeout 10. Необходимые действия и ресурсы должны быть публично описаны. summary.json разделяет доступность транспорта и фактический исход миссии. Прохождение локального peer не означает прохождения чужого сервера.

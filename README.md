# Ариадна

Программный комплекс для хакатона «Метарой 1.0». Разработчик: Заречкин Артём Алексеевич, Б24-507. Версия программы **0.9.0**, документы актуализированы **13 ноября 2026 года**.

Среда и контроллер запускаются отдельными процессами и взаимодействуют по HTTP/JSON. Контроллер меняет сценарии, роли и команды при отказах, потере связи и изменении задачи. Контрфактический штаб сравнивает варианты до исполнения, а журналы позволяют проверить решение и его результат.

## Запуск

Нужен Python 3.11 или новее. Запустите `start.bat` в Windows либо выполните из корня:

```bash
python3 scripts/start_local.py --open
```

Откроется [Квартира 42](http://127.0.0.1:8080/home.html). Полевые миссии доступны по кнопке интерфейса или адресу [/index.html](http://127.0.0.1:8080/index.html). Node.js и pip install для этого не требуются. Для просмотра готовых записей без нового расчёта можно открыть `viewer/home.html` или `viewer/index.html`.

В шестой полевой миссии **«Орбитальный мост»** работает спутник «Орбита 01»: на 4-й секунде отказывают наземные ретрансляторы, а он сохраняет передачу команд и выполнение нового SOS. Его каналы, роль, энергия и число обслуживаемых агентов видны в интерфейсе. Парная проверка: со спутником 100 % за 19 с, без спутника 0 % и безопасная остановка на 31 с. Это один модельный случай, журналы: `submission/cosmic_evidence.zip`. Полевые «Развилки» показывают две 2D-схемы с фактическими связями.

В квартире показаны обход затопленного входа, восстановление связи и остановка после закрытия кабинета. В поле доступны лес, карьер, город, полярная станция и дельта. «Решения», «Журнал» и «Развилка» раскрывают причины выбора и измеренные альтернативы. Офлайн-развилка собственной среды отделена от рабочего контроллера.

## Проверка и свидетельства

```bash
python3 -m unittest discover -s tests -v
python3 scripts/check_schemas.py
python3 scripts/check_scenarios.py
python3 scripts/check_delivery.py
python3 scripts/check_documents.py
python3 scripts/check_cosmic.py
```

Пересборка документов: `python3 scripts/build_documents.py --force --pdf` (python-docx, pypdf и LibreOffice). Дата редакции задана в `pyproject.toml`; программа и протокол сохраняют версии 0.9.0 и 1.0. После проверки документов и презентации выполните сборку и проверку архива по [инструкции](docs/SUBMISSION.md#3-проверка-и-сборка); его `MANIFEST.json` является манифестом поставки.

Проверка кода 13.11.2026: **206 тестов прошли**. Сохранённые **24** домашних и полевых прогона от 12.11.2026 повторно проверяются по журналам; **2** прогона спутниковой пары приведены отдельно. В текущих полевых расстановках переносимый контроллер завершил все пять миссий; fixed и reactive достигли лимита 180 с. Это результат внутренних детерминированных случаев, а не официальный турнирный балл.

[Сводка проверки кода](experiments/results/verification_2026-11-13.json), [историческая серия](experiments/results/verification_2026-11-12.json) и [первичные журналы](submission/verification_evidence.zip) фиксируют условия и хеши. Старые сводки и архивы сохранены с исходными версиями для воспроизведения поставленного просмотра. Их нельзя считать новыми измерениями 0.9.0.

Во время эпизода контроллер работает локально без LLM и API-ключей. [Роль генеративных инструментов](docs/ASSETS.md#4-роль-генеративных-инструментов-и-права). Реальных межкомандных и натурных испытаний нет; локальный `interop/peer.py` является нашим проверочным стендом.
